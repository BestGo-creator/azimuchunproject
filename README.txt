DISCIPLINED SCHOOL website (static, no animations)

Open index.html in any browser. No build step, no external files.

To finish:
1. Application form: open script.js and set SUBMIT_ENDPOINT to your form service URL
   (JSON POST). Until then the form shows "Not sent" and never claims success.
2. Images: the facilities pictures in the images folder are simple illustrations.
   To use real renders or photos, save them in images/ and change the src in index.html
   (for example src="images/classroom.jpg").
